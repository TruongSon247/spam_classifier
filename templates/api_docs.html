REST API Documentation

Tích hợp mô hình Multinomial Naïve Bayes vào ứng dụng bên ngoài.

Quản lý API Keys
PREDICTION

POST /api/v1/predict

Phân loại nội dung Email bằng model Naïve Bayes đang Active.

Headers

Content-Typeapplication/jsonBắt buộc
X-API-KeyAPI Key do Admin cấpBắt buộc

JSON Body

{
  "subject": "Prize",
  "text": "Congratulations! You won a free prize."
}

Response 200

{
  "success": true,
  "prediction": "spam",
  "spam_probability": 0.97,
  "ham_probability": 0.03,
  "confidence": 0.97,
  "model_version": "v0002",
  "model_outdated": false
}
STATUS

GET /api/v1/health

Kiểm tra dịch vụ, trạng thái model và phiên bản đang Active. Endpoint này không yêu cầu API Key.

Ví dụ PowerShell

$headers = @{ "X-API-Key" = "YOUR_API_KEY" }
$body = @{ text = "Congratulations! You won a free prize." } | ConvertTo-Json
Invoke-RestMethod -Method Post `
  -Uri "http://127.0.0.1:5000/api/v1/predict" `
  -Headers $headers -ContentType "application/json" -Body $body

Ví dụ Python

import requests

response = requests.post(
    "http://127.0.0.1:5000/api/v1/predict",
    headers={"X-API-Key": "YOUR_API_KEY"},
    json={"text": "Congratulations! You won a free prize."},
)
print(response.json())

Xác thực

Chỉ gửi API Key qua header X-API-Key. Không đặt key trong URL.

Quyền riêng tư

API không lưu subject hoặc nội dung Email, không tạo History hay Quarantine.

Production

Khi triển khai công khai, nên bổ sung HTTPS và rate limiting.
